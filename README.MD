# Labor Market Intelligence Platform (LMIP)

## Overview

The Labor Market Intelligence Platform (LMIP) is an end-to-end data analytics platform designed to collect, process, analyze, and visualize labor market data from multiple public job APIs.

The platform provides insights into hiring trends, salary distributions, in-demand skills, remote work opportunities, employer activity, and geographic employment patterns.

This project demonstrates a complete data analytics workflow, including data engineering, database design, SQL analytics, Python analysis, and business intelligence reporting.



## Objectives

 Collect job postings from multiple public job APIs.
 Build an automated ETL pipeline using Python.
 Store structured data in a MySQL relational database.
 Analyze labor market trends using SQL and Python.
 Develop interactive Power BI dashboards.
 Generate business insights for job seekers, recruiters, educators, and employers.
